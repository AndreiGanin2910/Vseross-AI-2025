# Всероссийская олимпиада по искусственному интеллекту — 2025

Финальные решения пяти задач соревнования. В репозитории оставлены только лучшие сохранённые варианты: без черновых экспериментов, локальных путей и громоздких служебных ячеек.

| Задача | Направление | Результат | Основной подход |
|---|---|---:|---|
| [A](task-a-audio/) | Детекция слова в аудио | **0.975** | XLS-R / Wav2Vec2 |
| [C](task-c-poi-rating/) | Оценка заведения | **0.81** | LightGBM + TF-IDF + geo |
| [D](task-d-product-dimensions/) | Габариты товара | **0.764** | CatBoost + TF-IDF + SigLIP |
| [E](task-e-rustore-classification/) | Категории RuStore | **0.926** | RuBERT, multilabel top-3 |
| [F](task-f-auto-pricing/) | Стоимость автомобиля | **0.820** | CatBoost + image embeddings |

## Структура

Каждая папка содержит один финальный `solution.ipynb` и отдельный README с описанием подхода, структуры данных и результата. Данные и тяжёлые артефакты моделей в Git не добавляются.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Далее откройте нужный ноутбук, положите данные в его локальную папку `data/` и выполните ячейки сверху вниз. Часть решений требует GPU и загрузки весов моделей из Hugging Face или timm.

> Значения leaderboard score перенесены из названий и комментариев исходных авторских ноутбуков; воспроизведение метрик требует оригинальных данных соревнования.
